## 💻 The code

Runnable Python for every chapter. Read a chapter, then run its folder.

| Folder | Matches | Run it |
|---|---|---|
| `basics/` | Part 1 | `python basics/max_and_min.py` |
| `arrays/` | Part 2 | `python arrays/array_utils.py` |
| `linked_list/` | Part 3 | `python linked_list/singly_linked_list.py` |
| `stack/` | Part 4 | `python stack/stack_list.py` |
| `queue/` | Part 4 | `python queue/circular_queue.py` |
| `search_sort/` | Part 5 | `python search_sort/compare_runtime.py` |
| `hashing/` | Part 6 | `python hashing/hash_utils.py` |
| `recursion/` | Part 7 | `python recursion/factorial.py` |

Every file has a `if __name__ == "__main__":` demo block, so running it shows the code working and prints the results.

## 🚀 How to use this

1. Read one book chapter.
2. Open the matching code folder and **run** the files.
3. Change the numbers. Break things. Watch.
4. Do the tasks at the end of the chapter.
5. Re-derive the idea from scratch a few days later.

Reading without running is not learning. Type the code yourself.

## 🐍 Requirements

Just Python 3.8+. No third-party packages — everything uses the standard library.

```bash
python --version
```
